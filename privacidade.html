Política de privacidade do TrendingCut

Última atualização: 15 de novembro de 2026

O TrendingCut é um aplicativo de uso pessoal, executado apenas no computador do seu dono, para publicar vídeos no canal do YouTube do próprio dono. Esta política explica quais dados o aplicativo acessa e como eles são tratados.

Dados acessados

Com a autorização dada pela tela de login do Google, o aplicativo acessa:

  • Permissão para enviar vídeos ao canal autorizado (escopo youtube.upload).
  • Nome e identificação do canal autorizado (escopo youtube.readonly).
  • Estatísticas dos vídeos do canal autorizado, como visualizações e retenção (escopo yt-analytics.readonly).

Como os dados são usados

  • Os vídeos são enviados somente quando o dono aprova cada envio.
  • O nome do canal é usado apenas para mostrar ao dono em qual canal o vídeo será publicado.
  • As estatísticas são usadas apenas para o dono acompanhar o desempenho dos próprios vídeos.

Armazenamento

O token de acesso e o nome do canal ficam salvos apenas no computador do dono. Nenhum dado é enviado a servidores próprios do aplicativo, porque eles não existem.

Compartilhamento

Nenhum dado obtido das APIs do Google é vendido, compartilhado ou transferido a terceiros, nem usado para publicidade.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O uso das APIs do YouTube também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Depois disso, o aplicativo não consegue mais enviar vídeos nem ler dados do canal.

Contato

Dúvidas sobre esta política: abra uma issue neste repositório.
